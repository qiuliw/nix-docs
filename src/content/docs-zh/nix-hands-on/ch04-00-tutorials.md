Nix 的基础知识已经掌握得足够充分了。接下来让我们实际用 Nix 来构建软件包吧。本教程将构建三种东西。

1. hello
2. Rust 项目
3. Docker 镜像

第一个是简单的 Hello world 程序。我们将学习 Flake 的搭建方法以及 stdenv 的基本用法。

第二个是带有依赖关系的 Rust 项目。当编程语言一侧存在依赖关系时，需要把这些信息引入到 Nix 中。这次我们以 Rust 为例来学习具体做法。

第三个则稍显另类。由于 Nix 具备通用的构建系统，因此除了广义上的软件包之外，还能构建各种各样的东西。这次我们就尝试用 Nix 来构建 Docker 镜像。
