## 官方参考文档

### Nix Reference Manual

这是关于 Nix 的概念、机制以及 Nix 语言规范的文档，其中也包含命令参考。本书参考的是 Nix 2.20 的参考手册。

https://nix.dev/manual/nix/2.20/introduction

### Nixpkgs Reference Manual

Nixpkgs 的参考手册。如果想详细了解 stdenv，请参阅这份文档。

https://nixos.org/manual/nixpkgs/stable/

## 教程

### Zero to Nix

这是 Determinate Systems 提供的动手实践形式的教程，可以学习基于 Flakes 的 Nix 用法。

https://zero-to-nix.com

### Nix Pills

官方教程。请注意，它并未讲解 Flakes、Nix command 等实验性功能。

https://nixos.org/guides/nix-pills/
