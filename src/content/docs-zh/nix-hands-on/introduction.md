## Nix 能做什么

在进入正文之前，我们先重新梳理一下 Nix 究竟能做些什么。

### 1. 声明式、可复现的构建 & 通用的软件包分发

这是最常见的用法。

用 Nix 语言以声明式的方式定义软件包的构建过程，从而实现构建自动化。得益于构建系统的高度可复现性，无论构建过程多么复杂，只要用 Nix 成功构建过一次，之后无论重复构建多少次，都能保证得到完全相同的产物。

此外，只要在 GitHub 等平台^[GitLab 以及归档形式的分发平台也同样可以发布。]上公开软件包定义，就能自由地共享软件包。使用者无需关心依赖关系问题和构建细节，就能简单、安全地使用这些软件包。

而最大的优势在于，软件包可以在任意 Linux 发行版和 macOS 之间共享。虽然作用范围仅限于用户环境，但你不再需要为每个系统使用不同的包管理器，软件包的分发得以统一。在编译器、运行时环境以及 CLI 工具的管理方面，它尤其是一件强大的利器。

### 2. 声明式地搭建开发环境

你也可以完全不做全局安装，只以项目为单位进行本地的软件包管理。

借助 **devShell** 这一功能，可以声明式地搭建开发环境。用 Nix 语言描述希望引入开发环境的软件包及其他配置，然后用 `nix develop` 命令启动开发用的 shell 即可。

与 Docker 不同，它不做虚拟化，而是利用 Nix 自身的独立性，因此没有额外开销。而且 devShell 本身就是一个普通的 shell，宿主系统上已经安装的各类工具依然可以继续使用。

## 本书的结构

最初的设想是采用

> Nix CLI 的用法 → Nix 语言 → 用 Nix 进行构建

这样自顶向下的结构。但根据读者对前篇的反馈以及笔者自身的经验，为了尽量减少妨碍学习的误解，最终改为

> Nix 语言 → Nix CLI 的用法 → 用 Nix 进行构建

这样从 Nix 语言起步、自底向上的结构。

如果你更喜欢自顶向下的学习方式，推荐阅读 [Zero to Nix](https://zero-to-nix.com)。

https://zero-to-nix.com

### 目录

本书分为以下四个部分：

1. Nix 语言
2. 实践 Nix
3. 构建工具
4. 教程

每一部分都包含若干与主题相应的小节。

「第 1 部：Nix 语言」在学习 Nix 语言基本写法的同时，也会深入探讨 Nix 语言是如何与 Nix 的构建系统协同工作的。接下来的「第 2 部：实践 Nix」会暂时离开对 Nix 内部机制的讲解，转而学习 CLI 操作等作为工具的使用方法，其中还包含了 devShell 这一出色的开发环境搭建功能的教程。

然后，在「第 3 部：构建工具」中学习 Nixpkgs 提供的、构建软件包时不可或缺的重要构建工具；在基础打牢之后，最后在「第 4 部：教程」中实际动手构建软件包。

与前篇一样，本书整体也是前后连贯的，因此建议按顺序阅读。

## 注意事项

Nix 语言求值以及命令执行所输出的 Store 路径，可能会因读者的环境而有所不同。请注意，实战示例中出现的 Store 路径字符串都隐含着「在笔者的环境中推导得出」这一前提。
